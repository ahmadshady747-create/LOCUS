## 1. Architectural Philosophy & Mission

`locus-engine` is a pure systems-level software verification and context compression engine engineered in 100% safe Rust. It eliminates runtime crashes and regressions generated by probabilistic AI coding tools before patches touch the physical filesystem, while compressing prompt context footprints by over 70%.

## 2. Mathematical Invariant Definitions (`AstGuard`)

`AstGuard::verify(source: &str) -> VerificationReport` executes 6 deterministic passes sequentially in `<0.05ms`:

### 2.1 Pass 0: Delimiter Balance (Dijkstra Stack)
Computes bracket matching closure $\Delta$:
$$\Delta = \text{Stack}(\{, [, () \quad \text{such that} \quad \text{pop}(\text{close}) = \text{open}$$
Strings are skipped with escape tracking (`\"`, `\'`). Unclosed or mismatched brackets trigger `ViolationKind::UnbalancedDelimiters`.

### 2.2 Pass 1: Async Concurrency Guard
Detects synchronous mutex guards held across async suspension points:
$$P_{\text{concurrency}} = \text{Regex}(\text{std::sync::Mutex}) \land \text{Regex}(.await)$$
Flags `ViolationKind::AsyncMutexAcrossAwait`.

### 2.3 Pass 2: Division-by-Zero Protection
Ensures all dynamic variable divisors are constrained:
$$x / y \implies y \neq 0 \lor y \neq 0.0 \lor \text{assert!}(y)$$
Literal numeric divisors ($x / 2$) are whitelisted. Violations trigger `ViolationKind::DivisionByZero`.

### 2.4 Pass 3: Array Bounds Overflow Guard
Ensures index accessors are protected by length predicates:
$$\text{arr}[i] \implies i < \text{arr.len()} \lor \text{arr.get}(i)$$
Violations trigger `ViolationKind::ArrayOutOfBounds`.

### 2.5 Pass 4: Unsafe Unwrap / Expect Trap
Traps unguarded `.unwrap()` and `.expect()` calls:
$$\text{opt.unwrap}() \implies \text{is\_some}() \lor \text{is\_ok}() \lor \text{if let}$$
Flags `ViolationKind::UnsafeUnwrap`.

### 2.6 Pass 5: ReDoS Catastrophic Backtracking Prevention
Identifies nested polynomial and exponential quantifiers in regex literals:
$$R_{\text{ReDoS}} = (a+)+ \lor (.*)* \implies O(2^n)$$
Flags `ViolationKind::ReDoSPattern`.

## 3. Cryptographic State Machine (`AstContextCache`)

Implements FIPS 180-4 Standard SHA-256 with 64-round compression in pure Rust:
- Constants: $K_{0..63}$ and initial hash values $H_{0..7}$.
- Padding: $M \parallel 1 \parallel 0^k \parallel L_{64}$.
- LRU Eviction: Monotonic sequence indexing via `AtomicU64` ensuring deterministic sub-millisecond eviction across all operating systems.

## 4. Model Context Protocol (MCP) Specification

Exposes stdio JSON-RPC 2.0 server with 4 standard tools:
1. `check_safety`: Invokes `AstGuard::verify`.
2. `skeletonize`: Invokes `AstDiffEngine::skeletonize`.
3. `patch_symbol`: Invokes `AstDiffEngine::patch`.
4. `index_graph`: Invokes `SymbolGraph::index_directory`.
